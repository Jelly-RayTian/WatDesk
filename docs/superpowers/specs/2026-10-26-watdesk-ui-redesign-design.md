# WatDesk 全面视觉重做方案

状态：用户已于 2026-10-26 确认，进入实现；此状态不代表界面已完成。

## 意图与已知需求

用户选择“整体换一套视觉设计”。WatDesk 仍是已有的浏览器学业工作台，常用场景是在约 360–440px 的 Edge 侧边栏里快速查课程、截止事项和考试，也需要完整桌面页。真实数据与提交状态必须可信，不能用新外观掩盖同步失败。本轮更新现有六个页面的视觉系统与信息组织，不新增平台。

## 方案比较与选择

- 保留黄白大圆角卡片，只修间距：改动小，但无法解决首屏层级分散、装饰占空间的问题。
- 整体重做现有工作台：用户已选择此方向。重新设计视觉系统和布局，同时保留原有业务能力。
- 推倒重做技术栈：没有必要，会扩大刚修复的数据流程的回归范围，不采用。

整体重做的具体视觉方向由我提议：**暖白纸面、深墨文字、克制的金色重点，像一张整理清楚的学业日程台**。不沿用当前满屏浅蓝、大圆角气泡和成排圆形工具按钮。

## 视觉系统

- 暖白背景，白色主要内容区，深墨色文字；金色仅用于当前日期、选中导航和主操作。课程色是小标记，不能成为整块背景。
- 用细分隔线、明确网格、8–12px 圆角区分内容；阴影限于浮层，不用大面积悬浮卡片。
- 沿用已打包的 Figtree 和系统中文字体，统一数字、字号、行高与字重；中英文、日期和长标题均需检查。
- 不新增运行时网络字体、图标 CDN、权限或框架。继续 React/Vite、现有 Phosphor 图标及原生 CSS。
- 浅色与深色均完整设计。动效只用于页面切换、展开与反馈，尊重减少动态效果偏好。

## 布局与信息层级

### 概览

首屏按“今天 → 最近的重要安排 → 按日期排列的即将到来事项”组织。今天的考试与截止任务分别明确展示，不能在有考试时只突出“今天没有任务截止”。不同时堆放重复摘要卡片。

课程筛选集中放在事项列表上方：优先显示有未完成或未来安排的课程，零项课程通过“全部课程”查看，切换时不丢记录。计数清楚区分未来安排与逾期项目；过期、未知提交状态不能算成已确认未提交。

列表以日期分组，每行保留课程、标题、时间、来源与状态。ECON Quiz、ENGL 大纲任务与正式考试均可在概览找到；较远日期通过展开/查看全部访问，不因只截取前八项而让课程看起来消失。

### 任务、考试与日历

任务使用紧凑的列表与清楚的完成操作。考试页区分固定考试时段、在线 Quiz 开放窗口与仅公布日期的项目。开放时间、截止时间、单次限时各自标注，不混用；未知时间不显示伪造的午夜。

月历与议程保持一致的课程标记，选中日期的安排直接可读。来源链接、个人备注、导出和原有编辑能力保留。

### 成绩与设置

成绩页先展示可用成绩及其核对状态，再展示趋势和估算。估算清楚区分于真实成绩。

设置按“连接与同步 → 课程与提醒 → 本地数据 → 高级诊断”分组。可选且停用的来源默认收起。原始错误码保留在诊断详情，不挤占正常阅读区域。

### 同步反馈

全局使用一条紧凑、始终可进入详情的状态区。明确区分正在读取、刚核对、使用缓存、部分可读、需用户处理。成功状态不长期占据首屏；失败和部分成功不共用一条笼统的“需要密码”文案。详细状态显示每个来源的最后成功时间与可执行操作。

## 响应式与可访问性

- 侧栏 360/400/440px：一列内容；固定底部导航保留中文/英文标签；顶部只保留高频操作，次要操作归入菜单。
- 桌面 1024/1280/1440px：左侧导航、主要日程和辅助信息形成稳定网格；内容有最大宽度，不无限拉伸。
- 页面无横向溢出；长课程名和长任务名不能遮住日期或操作；底部导航不能挡最后一条事项。
- 键盘操作、可见焦点、按钮标签、对比度和触控目标不能因精简而退化。不能只用颜色表达状态。

## 数据与实现边界

保留所有存储内容、课程隐藏设置、完成标记、来源开关、六小时同步配置、导入与导出语义。视觉重做不重新抓取或改写平台成绩，不启动测验，不改变后台临时页的所有权和关闭规则。

允许拆分当前较大的 App 组件，建立少量复用的布局、事项行、状态和筛选组件；具体文件拆分、图标与小间距由实现者决定。避免再次叠加一层覆盖样式，应合并现有重复的样式规则，保留可维护的令牌和组件层级。

## 验收

1. 在有真实数据的侧栏确认 ECON Module 7 与 ENGL Vlog 可发现，截止时间正确，导入记录不重复。
2. 浅色、深色、中英文，以及 360/400/440px 与桌面宽度均检查；无溢出、遮挡和不可达操作。
3. 在读取、缓存、部分成功、登录需处理、空数据等状态下检查反馈和下一步操作。
4. 原有测试、类型检查、构建和必要交互回归通过；重要改动有截图或实际界面证据。
5. 本机文件、浏览器已加载版本与实际源读取结果分别报告，不用 CI 成功代替实机验证。
